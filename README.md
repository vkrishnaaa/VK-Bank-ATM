# 🏧 VK Bank — ATM Management System

> My first Python mini-project. A simple ATM simulation built while learning Python, one feature at a time. 💻

Welcome to **VK Bank ATM** — a beginner-friendly, terminal-based ATM management system built using Python.

This project simulates a basic ATM experience where users can verify their account details, authenticate using a PIN, check their balance, deposit money, and withdraw funds.

Nothing too crazy for now. Just me turning Python basics into something that actually feels like a project. 🚀

## ✨ Features

- 🔐 **Account Verification** — Checks whether the entered account number matches the predefined account.
- 🔑 **PIN Authentication** — Verifies the user's PIN before allowing access to banking operations.
- 💰 **Balance Inquiry** — Displays the current account balance.
- 📥 **Cash Deposit** — Adds money to the balance when the entered amount is valid.
- 📤 **Cash Withdrawal** — Allows withdrawals within the available balance.
- 🚪 **Exit Option** — Ends the ATM session.
- 💬 **Interactive Terminal Interface** — Uses input prompts and messages to simulate a basic ATM experience.

## ▶️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/vkrishnaaa/VK-Bank-ATM.git
```

### 2. Open the project folder

```bash
cd VK-Bank-ATM
```

### 3. Run the program

Make sure Python 3 is installed, then execute:

```bash
python atm.py
```

On some systems, you may need:

```bash
python3 atm.py
```

## 🧪 How It Works

1. Start the program.
2. Confirm whether you have an account.
3. Enter your name and account number.
4. Enter the predefined PIN.
5. Choose an available operation from the ATM menu.
6. Follow the prompts to check your balance, deposit money, withdraw money, or exit.

## ⚙️ Demo Configuration

The current version uses predefined values for demonstration purposes.

- **Initial balance:** 1000
- **Account number:** Hardcoded in the source code
- **PIN:** Hardcoded in the source code

These values are intended only for local testing and learning.

⚠️ **Security note:** This is an educational simulation, not a real banking application. It does not use secure authentication, a database, or persistent account storage. Do not use real banking credentials or financial information.
